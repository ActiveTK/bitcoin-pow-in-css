# bitcoin-pow-in-css

Bitcoin's Proof of Work (double SHA-256 over a block header), written in CSS. No JavaScript.

Demo: https://bitcoin-pow-in-css.activetk.jp/

## Run

```
docker compose up --build
```

Then open http://localhost:8080/ and press Start.

Without Docker:

```
pip install aiohttp
POOL_MODE=fake python3 server/app.py
```

Set `POOL_MODE=stratum` (and `POOL_HOST`, `POOL_PORT`, `POOL_USER`) in `docker-compose.yml` to take jobs from a real pool.
The stylesheet `public/miner.css` is generated by `cd tools && python3 build_miner.py`.
